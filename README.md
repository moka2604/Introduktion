## git add använder man när man vill lägga till alla ändrade filer på en gång medan git commit använder man för att beskriva ändringarna man har gjort på sidan
## Man använder branches för att kunna testa en idé utan att påverka koden i main och sen om det blir bra kan man merga samman dom
## När du mergar alltså skapar en Pull Request så överför du ändringar från en branch till en annan
## Om man pushar till Github så skickar man ändringar i koden medan att publicera på Netlify visar hela webbplatsen
## Om du vill versionshantera en specifik fil så skriver du git add filnamn.html, man kan också använda gitignore om man vill exkludera en specifik fil från versionshanteringen
